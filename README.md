This is a Jupyter Notebook file to scrap fuel prices from those forecourt operators that took part in the voluntary fuel price data collection service
operated by the Competitions and Marketing Authority of the UK government.

The service has since been superseded by the UK government Fuel Finder service - however, as of 17 March, 2026, the voluntary data is still being
submitted and is searchable.

The new service can be found at [UK government fuel finder](https://www.gov.uk/guidance/access-the-latest-fuel-prices-and-forecourt-data-via-api-or-email)
where it can be accessed via .CSV or using the API service.

This scraper notebook script downloads json data generated by the main forecourt operators, and then sorts it for Scotland only postcodes.
There is a possibility that PRL and MFG forecourt data is duplicated - this can be removed by manually checking duplicates generated by the Jupytyer script.

Dependencies: BeautifulSoup4, Pandas, Requests, Openpyxl
